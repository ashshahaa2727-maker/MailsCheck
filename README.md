# mailscheck

mailscheck — утилита для Windows 10 и 11. Она скачивает программы из каталога и открывает готовые запросы в Everything для ручной проверки файлов Minecraft.

## Загрузка программ

1. Запустите `mailscheck.exe`. Windows может запросить права администратора.
2. Прокрутите каталог, чтобы найти нужную утилиту. На каждой карточке указано, для чего нужна программа.
3. Нажмите на карточку, чтобы скачать одну программу, или **Скачать всё**, чтобы скачать все программы каталога.
4. Следите за ходом загрузки в журнале. Нажмите **Открыть папку**, чтобы перейти в `Загрузки\holycheck`.

ZIP-архивы распаковываются в отдельные папки. Скачанные программы и установщики запускаются вручную из папки загрузок.

## Поиск в Everything

- **Проверить читы** ищет по заданным ключевым словам в именах файлов `.exe`, `.jar`, `.zip` и `.rar`.
- **Проверить конфиги** ищет по второму списку слов в именах папок и файлов `.txt`, `.json`, `.toml`, `.yml`, `.cfg`, `.properties` и `.ini`, изменённых за последние 14 дней.

Кнопки открывают запрос в Everything. Если утилита не найдена, mailscheck предложит её скачать. После загрузки нажмите кнопку поиска ещё раз. Запрос также можно вставить в Everything вручную из буфера обмена.

Everything ищет в проиндексированных папках. Совпадение имени, особенно по общему слову вроде `auto` или `player`, нужно проверять вручную.

## Сборка

Откройте **Developer Command Prompt for VS** с установленными Visual Studio Build Tools и Windows SDK. В корне проекта выполните:

```bat
cl /std:c++17 /EHsc /O2 /MT /utf-8 /DUNICODE /D_UNICODE main.cpp /Fe:mailscheck.exe /link /SUBSYSTEM:WINDOWS user32.lib gdi32.lib comctl32.lib shell32.lib shlwapi.lib winhttp.lib wininet.lib ole32.lib oleaut32.lib uuid.lib dwmapi.lib gdiplus.lib advapi32.lib
```

Готовый `mailscheck.exe` запускается без отдельной установки Visual C++ Redistributable. Некоторые программы из каталога требуют Java или .NET.
